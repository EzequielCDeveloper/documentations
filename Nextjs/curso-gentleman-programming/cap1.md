## Index

### Ventajas

- Popularidad: Framework basado en react
- Build muy rapido

- **Lazy loading** y **Code splitting**
  - **Lazy loading:** Posibilidad de generar cosas, solo cuando se necesitan. Se genera el bundle.js con todo el codigo, cuando vaya a renderizar el usuario el codigo de la web, indicara que codigo darle al cliente y que generar.

### SEO

Implementar mejoras para tener un mejor posicionamiento en los motores de busqueda. Servidor se encarga de renderizar la pagina, pero eso no implica al JS. Una vez el usuario recibe el html, es el mismo usuario el que se encarga de hidratar la pagina al terminar de cargar el js.

Server sending ready to be rendered HTML reponse to browser -> browser renderes the page now viewable, and browser downloads JS. -> Browser exectues react. -> page now and reactable
