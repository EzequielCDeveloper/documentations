Gentleman Setup

Steps
 - Ensure runtime (Node >=16 or Python 3.10) installed
 - Add agent entry to skill registry (see AgentsAI/skills.md)
 - Provide env vars if the agent calls external APIs

Quick test
 - Run a dry-run: `gentleman --dry-run review ./path/to/file`

Conventions
 - Use polite commit messages and small, reversible changes
