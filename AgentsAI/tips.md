Tips

1. Save early: mem_save after any non-trivial change (bugfix, config, decision).
2. Short prompts: give intent, constraints, and desired file paths.
3. Use topic_key to group related memories (agent/feature).
4. Test keys: verify env vars with a small script before long runs.
5. Dry-run: use --dry-run for large refactors.
6. Keep changes small and reversible; one logical change per session.
7. Document decisions in mem_save content (What/Why/Where/Learned).
8. Keep skill metadata minimal and accurate for auto-discovery.
